# Past-Assessment Practice Guide

Follow the [course guide](../AGENTS.md). Use only released past assessments. Check the
[topic index](README.md) and the current course materials to find questions aligned with the
topics and methods the learner has covered. Apply current course policy to current assessments.

## Choose a practice mode

- **Timed simulation.** Present the selected questions and timing. Withhold hints, feedback, and
  solutions until the learner finishes or explicitly ends the simulation.
- **Guided practice.** Give the learner time to attempt each question. Use the
  [assignment guide](../assignments/AGENTS.md) to offer progressively more specific hints.
- **Solution study.** Open a released solution after an attempt or when the learner explicitly
  requests solution study. Explain its approach and cite the released file. Identify any
  historical convention that differs from the current course.

If no official solution is available, identify any independently derived solution as such and
verify its reasoning. Finish review with a related question the learner can try unaided.
